# World Bias Explorer

Create a modern Korean-style editorial website called 'World Bias'. The website explores stereotypes and hidden truths about different countries in a playful, pastel, Gen Z aesthetic.

Design requirements:
- Soft pastel beige background (#f8f5ea)
- Rounded cards with subtle shadows
- Large bold Korean typography similar to Pretendard Black
- Cute pink buttons and badges
- Modern editorial/blog layout
- Responsive for mobile and desktop
- Use playful emojis and soft gradients
- Smooth hover animations

Navbar:
- Left logo: globe emoji + text 'World Bias'
- Right menu: 홈 / 퀴즈 / 소개 / pink CTA button '퀴즈 시작하기'
- Sticky top navigation with white background

Hero section:
- Large headline: '세상의 편견을 탐험해요'
- Subtitle about exploring misconceptions about countries
- Black rounded CTA button
- Decorative pastel world map illustration area
- Pink and pastel decorative elements

Country section:
- Title: '어떤 나라를 탐험할까?'
- 8 pastel country cards in grid layout
- Each card includes emoji flag, Korean country name, English subtitle, short description, article count badge, explore link
- Countries: 한국, 미국, 일본, 프랑스, 브라질, 이탈리아, 영국, 인도
- Each card has different pastel background color

Popular article section:
- Large section title '오늘의 인기 기사'
- Grid of modern article cards with large cover images
- Each article has category pill, title, description, date, and views
- Rounded image cards with soft shadow
- Hover lift effect
- Include at least 6 sample article cards

Styling:
- Use Google fonts Pretendard or similar
- Strong oversized Korean headings
- Soft feminine Gen Z aesthetic
- Spacing similar to premium editorial websites
- Use realistic placeholder images

Technical requirements:
- Build with React + Tailwind
- Fully responsive
- Clean component structure
- Smooth animations
- Modern UI/UX
- Production-ready landing page

Also include:
- Footer section
- Scroll animations
- Responsive mobile menu
- Reusable components for cards
- Nice transitions and micro-interactions
